# Cross-Repo Validation Gate Matrix

Chinese mirror: `cross-repo-validation-gate-matrix.zh.md`.

Gate 0 is v0.8 plan readiness. Gate 1 is WorldEngine v0.9 public contract
readiness. Gate 2 is Validation Client implementation readiness. Gate 3 is
Codex autonomous validation. Gate 4 is second-Agent read-only review. Gate 5 is
human validation.

Client smoke, API tests, or export success do not equal WorldEngine validation
PASS.
