# Second-Agent Review Template

Chinese mirror: `second-agent-review-template.zh.md`.

Review inputs include result, operation log, API log, API summary, manifest,
scenario artifacts, redaction scan, scorecard summary, screenshots, and
transcript.

The reviewer checks planned-step coverage, operation/API separation, required
artifact honesty, status preservation, redaction cleanliness, checker verdict
source, and unsupported client-owned PASS claims.
