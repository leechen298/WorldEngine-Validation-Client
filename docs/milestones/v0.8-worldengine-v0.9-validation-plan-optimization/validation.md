# v0.8 Validation Plan

Chinese mirror: `validation.zh.md`.

Codex autonomous validation proves only that the client, evidence, redaction,
and checker handoff are ready for the next gate. It does not declare world
experience, Agent naturalness, or LLM-backed full-lifecycle PASS.

Allowed conclusions are `PASS_READY_FOR_HUMAN_VALIDATION`, `PARTIAL`,
`BLOCKED`, and `FAIL`.
