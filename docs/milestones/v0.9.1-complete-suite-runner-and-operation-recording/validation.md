# Validation

Chinese mirror: `validation.zh.md`.

## Verdicts

| Verdict | Condition |
| --- | --- |
| `PASS` | Phase 1-4 required evidence exists, redaction passes, and checker/scorecard or second-Agent review supports PASS. |
| `PARTIAL` | Core UI operation and record chain works, with non-blocking evidence gaps and no redaction failure. |
| `BLOCKED` | WorldEngine capability, checker, environment, permission, or client-control gap prevents completion. |
| `FAIL` | Product behavior failure, false PASS claim, redaction leak, or provider/private boundary violation. |

The Chinese mirror defines the detailed review checklist and PASS source rules.
